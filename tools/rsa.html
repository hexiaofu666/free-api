关于RSA加密解密介绍：

  1. RSA 是非对称加密：公钥可以公开用于加密，私钥必须保密用于解密；私钥泄露则加密形同虚设。
  2. 本工具使用 RSA-OAEP 填充（比已废弃的 PKCS#1 v1.5 更安全），哈希可选 SHA-256 与 SHA-1。
  3. RSA 只能加密很短的数据：2048 位 + SHA-256 时单次上限为 190 字节，长文本请改用「对称加密 + 用 RSA 传密钥」的方式。
  4. 生成的密钥在浏览器本地产生，刷新页面即消失；如需长期使用请自行复制 PEM 并妥善保管私钥。
  5. 1024 位密钥已不满足现代安全要求，仅用于兼容测试；实际使用建议 2048 位及以上。
