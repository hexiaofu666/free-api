关于代码格式化压缩介绍：

    
    
      
  1. 支持 HTML、CSS、JavaScript 三种语言的格式化（美化缩进）与压缩（去注释、去多余空白）。
    2. 
      
  2. HTML 格式化：按标签层级缩进，脚本、样式、文本域等内容保持不变；压缩会删除注释并合并标签间空白。
    3. 
      
  3. CSS 格式化：选择器与声明分行显示；压缩会移除全部注释与多余空格、末尾分号。
    4. 
      
  4. JavaScript 压缩采用保守策略：仅删除注释与行首尾空白、跳过空行，不做变量混淆与跨行合并，避免破坏自动分号插入（ASI）语义。
    5. 
      
  5. 「转义为字符串」可把代码转成可嵌入 JS/JSON 的字符串字面量，方便动态注入。
    6. 
      
  6. 所有处理都在浏览器本地完成，代码不会上传服务器。
    7.
