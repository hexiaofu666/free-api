关于JSON转C#实体类介绍：

  1. 生成的类可直接配合 Newtonsoft.Json（JsonConvert.DeserializeObject）或 System.Text.Json 使用。
  2. C# 属性名使用 PascalCase（首字母大写），与 JSON 的 key 不一致时可用 [JsonProperty("key")] 标注。
  3. 类型映射：整数→int（超范围→long）、小数→double、布尔→bool、字符串→string、数组→List。
  4. 开启「可空引用」会把 string 写成 string?，适配 C# 8.0 以上开启 Nullable 的项目。
  5. 嵌套对象会生成独立的 public class，字段名相同的层级会自动去重以避免命名冲突。
