字体预览：词海工具箱 ABCabc 12345

关于本机字体检测介绍：

  1. 检测原理：把待测字体与三种基准字体的组合渲染到 canvas，比较文本宽度，宽度发生变化即说明该字体存在。
  2. 同一字体在不同系统上的名称不同（如 Windows 叫「微软雅黑」，macOS 叫「苹方」），网页 CSS 里通常写成字体栈依次回退。
  3. 网页设计中建议始终写字体栈（如 PingFang SC, Microsoft YaHei, sans-serif），避免在缺少字体的系统上显示异常。
  4. 部分浏览器出于隐私保护会限制字体枚举，检测结果可能存在个别偏差，重要场景建议以实际渲染效果为准。
  5. 若需要跨平台一致的效果，可使用 Web Font（如思源黑体）通过 @font-face 加载，代价是首次加载需要下载字体文件。
