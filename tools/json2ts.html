关于JSON转TypeScript介绍：

    
    
      
  1. 前端调用接口后，把返回的 JSON 粘贴进来即可得到完整 TypeScript 类型定义，省去手写 interface 的时间。
    2. 
      
  2. 类型推断规则：字符串 → string、整数与小数 → number、真假 → boolean、null 与混合类型 → 联合类型或 any。
    3. 
      
  3. 数组会自动合并所有元素的字段，某个字段不是每个元素都存在时会标记为可选（field?: T）。
    4. 
      
  4. 嵌套对象会根据键名生成独立的 interface，命名冲突时自动加序号后缀。
    5. 
      
  5. 空数组推断为 any[]，可生成后手动替换为具体类型。
    6. 
      
  6. 所有转换都在本地完成，接口数据不会上传服务器。
    7.
