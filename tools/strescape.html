关于字符串转义工具介绍：

  1. 十六进制转义把文本按 UTF-8 字节逐字节写成 \\xHH，适合嵌入 C / Python / JS 字符串；中文会占 3 个字节。
  2. Unicode 转义按 UTF-16 码元写成 \\uHHHH，字母数字保持原样可读，适合 JS 源码使用。
  3. HTML 实体有十进制 &#NN; 与十六进制 &#xHH; 两种写法，浏览器渲染结果一致，常用于防爬虫与转义尖括号。
  4. 「解码」会依次识别 HTML 实体、Unicode、十六进制、八进制与 URL 编码，可把混用的转义串还原。
  5. URL 编码遵循 encodeURIComponent 规则，中文与特殊字符会被转成 %XX 形式。
