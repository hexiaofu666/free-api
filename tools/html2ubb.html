关于HTML与UBB互转介绍：

  1. UBB 是论坛常用的轻量标记语言，用 [b]、[url]、[img] 等方括号标签代替 HTML 尖括号，可防止注入。
  2. 支持的 HTML 标签包括 strong/b、em/i、u、s/del、a、img、blockquote、code/pre、ul/ol/li 与 h1-h6。
  3. UBB 转为 HTML 时，链接会自动补上 target=_blank 与 rel=noopener，避免被劫持 window.opener。
  4. 论坛通常不允许直接粘贴 HTML，先用本工具转成 UBB 再发帖，可以保留加粗、链接与图片效果。
  5. 不同论坛的 UBB 方言略有差别（如 [flash]、[media]），本工具覆盖最通用的标准标签。
