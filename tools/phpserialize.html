序列化结果

关于PHP序列化工具介绍：

  1. PHP 序列化格式用类型前缀标记每种值：s:长度:字符串、i:整数、d:浮点、b:布尔、N:null、a:数量:{键值对}、O:类名长度:类名:属性数:{}。
  2. 字符串长度按 UTF-8 字节数计算，一个汉字占 3 字节，与 PHP 的 strlen() 结果一致。
  3. JSON 对象默认序列化为关联数组 a:N:{}；如需与 PHP 对象兼容（如缓存中存储的对象），可切换为 O:8:"stdClass" 形式。
  4. 序列化结果可用于生成数据库种子数据、缓存键值或与其他 PHP 系统交换数据。
  5. PHP 反序列化存在对象注入风险，生产环境请只反序列化可信来源的数据。
