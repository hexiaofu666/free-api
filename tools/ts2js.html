关于TypeScript转JavaScript介绍：

  1. 移除的类型信息包括：变量与参数类型注解、函数返回类型、interface、type 别名、as 断言、非空断言 ! 与调用处的泛型参数。
  2. 处理时会跳过字符串与注释，因此字符串里的「: number」不会被误删。
  3. enum 默认转成普通对象（带初始值计算），也可选择保留 enum 交给真正的 TypeScript 编译器处理。
  4. 本工具是轻量正则+状态机实现，复杂的条件类型、装饰器与命名空间建议使用 tsc 或 esbuild 编译。
  5. 转换后的代码是标准 ES 语法，可直接在浏览器或 Node.js 中运行。
