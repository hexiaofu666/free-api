简介

词海工具箱开放 API 为开发者提供常用的轻量计算接口，免费开放，无需注册。为保障服务质量，每个 IP 每天可调用 100 次（次日 0 点自动重置），超出将返回 429 状态码。

支持 GET 与 POST（POST 传 JSON body），响应统一为 JSON：{"ok":true,"data":{...}}，出错时为 {"ok":false,"error":"原因"}。已开启 CORS，可直接在浏览器前端调用。

接口列表

接口说明参数
/api/md5MD5 加密（32位/16位）text 文本
/api/sha256SHA 哈希（sha1/sha256/sha512）text 文本，alg 可选
/api/base64Base64 编码 / 解码text，mode=encode|decode
/api/urlURL 编码 / 解码text，mode=encode|decode
/api/timestamp时间戳转日期（缺省为当前时间）ts 秒级/毫秒级均可
/api/uuid批量生成 UUID v4（1-50 个）n 数量

调用示例

GET https://你的域名/api/md5?text=hello

响应：
{
  "ok": true,
  "data": { "text": "hello", "md5": "5d41402abc4b2a76b9719d911017c592", "md5_16": "bc4b2a76b9719d91" }
}
GET https://你的域名/api/timestamp?ts=1695456000

响应：
{
  "ok": true,
  "data": { "timestamp": 1695456000, "datetime": "2023-09-23 16:00:00", "iso": "...", "weekday": "六" }
}

限流说明

每次调用响应头会携带 X-RateLimit-Limit（每日配额）、X-RateLimit-Remaining（当日剩余次数）、X-RateLimit-Reset（重置时间），请在客户端做好缓存，避免浪费配额。超限返回 429。

温馨提示：

  1. 本 API 免费开放，请勿用于非法用途或高频滥用。
  2. MD5 / SHA 为单向哈希，仅用于校验，不可用于密码明文存储加密以外的安全场景。
  3. 接口后续会持续增加，如有需要欢迎通过 GitHub 提出。
