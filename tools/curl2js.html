关于cURL转JS介绍：

    
    
      
  1. 把浏览器复制的 cURL 命令转换为可直接使用的 JavaScript 请求代码，支持三种目标：原生 fetch、axios、Node.js 原生 http/https 模块。
    2. 
      
  2. 自动解析请求方法、请求头、请求体；识别 JSON 请求体时会生成 JSON.stringify() 或对象字面量写法。
    3. 
      
  3. axios 版本需要先 npm install axios；Node.js 版本使用内置模块，无需依赖。
    4. 
      
  4. GET 请求带查询参数时会保留在 URL 中；POST 表单（-F）会转换为 FormData。
    5. 
      
  5. 所有解析均在本地完成，不联网、不上传数据。
    6.
