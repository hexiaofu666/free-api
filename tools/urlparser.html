输入要解析的 URL（输入即自动解析）

查询参数明细

关于URL解析器工具介绍：

  1. URL解析器可把一个完整网址拆解为协议（Scheme）、域名（Hostname）、端口（Port）、路径（Path）、查询参数（Query）和哈希（Hash）等组成部分。
  2. 解析基于浏览器原生 URL API 与正则双重引擎，兼容 http、https、ftp 等常见协议格式。
  3. 查询参数部分会自动按 & 分隔并逐项解码展示，方便核对参数名与参数值。
  4. 支持中文与特殊字符：解析结果同时给出编码原值与解码后的可读值。
  5. 所有解析均在本地浏览器完成，数据不会上传服务器，安全放心。
