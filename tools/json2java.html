关于JSON转Java实体类介绍：

  1. 把接口返回的 JSON 粘贴进来即可生成对应的 Java 实体类，嵌套对象会自动生成静态内部类。
  2. 类型推断规则：整数→Integer（超过 21 亿转 Long）、小数→Double、true/false→Boolean、字符串→String、数组→List。
  3. 对象数组会按第一个元素的字段结构生成模板类，因此建议样例中包含完整的字段，避免漏字段。
  4. JSON 字段名会转成小驼峰（user_name / user-name → userName）；数字开头的字段名建议手动调整。
  5. 配合 Jackson / FastJSON 使用时，若字段名与 JSON key 不一致，需要额外加 @JsonProperty 注解。
