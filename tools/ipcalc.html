输入 IP 地址（支持 CIDR 如 192.168.1.10/24，或直接填掩码如 192.168.1.10/255.255.255.0）

关于IP子网计算器介绍：

  1. 子网划分是网络运维的基础操作，本工具可快速算出网段信息，免去手工二进制换算。
  2. 输入格式支持：192.168.1.10/24（CIDR 前缀）、192.168.1.10/255.255.255.0（点分掩码）、或仅输入 192.168.1.10（默认 /24）。
  3. 计算结果包括：网络地址、广播地址、可用地址范围与数量、子网掩码、通配符掩码（反掩码）。
  4. 会同时给出 IP 类别（A/B/C/D/E）、私有/公网判断以及二进制形式，便于理解按位运算过程。
  5. 特殊网段：/31 用于点对点链路（2 个地址均可用），/32 表示单个主机地址。
  6. 所有计算在本地浏览器完成，输入的 IP 不会上传服务器。
