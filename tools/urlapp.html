关于网站桌面快捷方式介绍：

  1. .url 是 Windows 的纯文本快捷方式格式，只需 [InternetShortcut] 段与 URL= 一行，IconFile= 可指定自定义图标。
  2. 最简单的做法是：在浏览器里把地址栏左侧的图标直接拖到桌面，系统会自动创建快捷方式，无需任何代码。
  3. 手机端「添加到主屏幕」会读取页面的 apple-touch-icon 与 theme-color，配合 manifest 可实现接近原生 App 的全屏体验。
  4. Windows 快捷方式的图标建议使用 ICO 格式，PNG 有时无法正常显示，尺寸推荐 48×48 或 256×256。
  5. 生成的 .url 文件是纯文本，可安全地用记事本打开查看与修改。
