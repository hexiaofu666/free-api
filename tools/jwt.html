关于JWT在线解密介绍：

  1. JWT（JSON Web Token）由三段组成，用英文句点分隔：头部.载荷.签名；前两段是 Base64URL 编码的 JSON。
  2. 解析只是解码展示，不代表签名有效：本工具不校验签名（校验需要密钥），仅用于查看内容与有效期。
  3. exp 是过期时间、nbf 是生效时间、iat 是签发时间，均为 Unix 时间戳（秒）；注意服务器时间与自己设备时间可能有偏差。
  4. 载荷内容是明文可见的，切勿把密码、身份证号等敏感信息直接放进 JWT 载荷。
  5. alg 为 none 的 token 表示无签名，任何一方都能伪造，生产环境必须拒绝接受这类 token。
