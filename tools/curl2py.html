关于cURL转Python介绍：

    
    
      
  1. cURL 是命令行 HTTP 请求工具，浏览器的「Copy as cURL」可把任意请求完整复制下来，本工具将其转换为 Python requests 代码。
    2. 
      
  2. 支持解析：-X 请求方法、-H 请求头、-d/--data 请求体、-F 表单上传、-u basic 认证、-b Cookie、-k 忽略证书、-L 跟随跳转、--compressed。
    3. 
      
  3. 自动识别 JSON 请求体：当 Content-Type 为 application/json 时会给出 json= 的写法提示。
    4. 
      
  4. 生成的代码使用标准 requests 库，需 pip install requests 后运行。
    5. 
      
  5. 所有解析均在浏览器本地完成，请求内容不会上传服务器，可放心处理含 Token 的命令。
    6.
