实时预览

关于HTML代码调试预览介绍：

  1. 「仅片段」模式会自动补全 DOCTYPE、head 与 body，直接粘贴一段 div 或表格代码就能看到效果。
  2. 预览区使用 iframe 隔离运行，脚本不会影响本页面的其它功能，可放心测试。
  3. 沙箱权限默认只开放脚本执行；若代码需要通过 fetch 读取接口或使用 localStorage，需选择「允许脚本+同源」。
  4. 点「查看完整文档」可得到补全后的完整 HTML 源码，复制后另存为 .html 文件即为一个独立网页。
  5. 调试响应式布局时，可先改浏览器窗口宽度，或把代码粘贴到手机浏览器中查看实际效果。
