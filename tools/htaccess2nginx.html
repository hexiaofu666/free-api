转换后的 Nginx 配置

关于 htaccess 转 Nginx 工具介绍：

  1. Apache 使用 .htaccess 文件配置重写规则，Nginx 需在 server 块中写 rewrite / if 指令，本工具帮您自动转换。
  2. 支持转换：RewriteRule（含 R=301/302 永久/临时跳转、L 标记）、RewriteCond（HTTP_HOST 等条件）、Redirect、ErrorDocument、Options -Indexes、DirectoryIndex、Deny from all。
  3. 转换结果需放在 server 块中，若原文要求放在 location / 内，请按注释提示调整位置。
  4. Nginx 的 if 指令有「if is evil」的说法，涉及复杂逻辑时建议改写为 map 或 location 匹配。
  5. 无法识别的行会以注释形式保留（带「未转换」标记），便于人工补写。
  6. 所有转换在本地浏览器完成，配置内容不会上传服务器。
