关于JSONPath查询介绍：

    
    
      
  1. JSONPath 是 JSON 的「XPath」，用路径表达式从复杂结构中提取需要的数据。
    2. 
      
  2. 支持语法：$ 根节点、.key 子节点、['key'] 方括号取值、[*] 或 .* 通配、..key 递归下降、[0] 下标（支持负数）、[1:3] 切片、[0,2] 联合、[?(@.price>10)] 过滤。
    3. 
      
  3. 过滤表达式支持 ==、!=、>、<、>=、<=、=~（正则匹配），右侧可写数字、字符串或布尔值。
    4. 
      
  4. 查询结果统一以数组形式展示，未匹配到结果显示空数组 []。
    5. 
      
  5. 所有计算在本地完成，数据不会上传。
    6.
