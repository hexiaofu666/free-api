关于SQL转Java实体类介绍：

  1. 支持 MySQL 建表语句中的 bigint/int/tinyint/varchar/char/text/decimal/double/float/datetime/date/timestamp/blob/json 等常见类型映射。
  2. 字段名会自动转为小驼峰属性名（user_name → userName），并保留 COMMENT 作为字段注释。
  3. Lombok 模式只生成 @Data 注解与字段，代码最简洁；完整模式会生成 Getter/Setter，适合不引入 Lombok 的项目。
  4. 主键、非空与 AUTO_INCREMENT 会被识别并在「查看字段解析」中标注，便于核对映射是否正确。
  5. 生成结果可直接复制进 IDE，注意包名与类名需与项目已有结构保持一致。
