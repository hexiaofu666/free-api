关于 Shield Badge 介绍：

  1. Shield Badge 是盾牌形状的小徽章，广泛用于 GitHub 仓库、技术文档，直观展示版本号、构建状态、许可证等信息。
  2. 本工具可视化设置左右两块的文字、背景色与文字颜色，并实时渲染 SVG 预览，无需联网即可查看效果。
  3. 支持 flat（扁平）、flat-square（方角）、plastic（立体）、for-the-badge（大字）四种主流样式。
  4. 可选择 GitHub、Vue、React、Nginx 等常见品牌图标（基于 Simple Icons）。
  5. 生成结果同时给出图片链接、Markdown 与 HTML 三种代码，可直接粘贴到 README 或网页中。
  6. 提示：图片链接指向 shields.io 公共渲染服务，国内访问可能较慢，可改用本地 SVG。
