关于希尔密码介绍：

  1. 希尔密码（Hill Cipher）由数学家 Lester S. Hill 于 1929 年发明，是历史上第一个实用的多字母替换密码。
  2. 核心是矩阵运算：明文按 n 个字母分组，与密钥矩阵相乘取模 26，得到密文分组。公式：C = K × P (mod 26)。
  3. 解密使用密钥矩阵在模 26 下的逆矩阵：P = K⁻¹ × C (mod 26)。
  4. 支持 2×2 与 3×3 矩阵、A=0 与 A=1 两种映射模式（部分教材采用 A=1…Z=26）。
  5. 非字母字符自动过滤，明文长度不足自动补 X；密钥矩阵必须在模 26 下可逆（行列式与 26 互质），否则无法解密。
  6. 示例：密钥矩阵 3 3 / 2 5，A=0 模式加密 HELP 得到 HIAT。
