关于JSON与YAML互转介绍：

    
    
      
  1. YAML 以缩进表达层级，可读性优于 JSON，广泛用于 Kubernetes、Docker Compose、GitHub Actions 等配置文件。
    2. 
      
  2. JSON 转 YAML：支持对象、数组、嵌套结构，标量自动判断是否需加引号（含特殊字符、看起来像数字或布尔的字符串会被引号包裹）。
    3. 
      
  3. YAML 转 JSON：支持块级映射、序列（- 开头）、- key: value 内联映射、行内注释（#）、单双引号字符串与常见标量类型。
    4. 
      
  4. 提示：YAML 的 true/false/null/数字 会被还原为对应 JSON 类型，加了引号的 "123" 会保持字符串。
    5. 
      
  5. 转换全程在本地浏览器完成，不上传任何数据。
    6.
