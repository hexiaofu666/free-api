关于XML与JSON互转介绍：

    
    
      
  1. XML 与 JSON 是两种常见的数据交换格式，本工具支持双向转换，方便接口调试与数据迁移。
    2. 
      
  2. XML 转 JSON 规则：元素名作为键；属性名加前缀（默认 @）；纯文本节点直接取值或多键时放入 #text；同名重复元素自动合并为数组。
    3. 
      
  3. JSON 转 XML 规则：以 @ 开头的键作为属性；#text 作为元素文本；数组会展开为多个同名元素；空对象输出自闭合标签。
    4. 
      
  4. 支持解析 XML 声明、注释、CDATA 段，自动还原 &lt; &gt; &amp; &quot; 等实体。
    5. 
      
  5. 转换在浏览器本地完成，数据不会上传服务器。
    6.
