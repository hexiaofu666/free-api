关于HTML转JS代码介绍：

  1. HTML 里的双引号、换行与制表符会被自动转义，因此生成的 JS 字符串可直接放进 script 标签中运行。
  2. document.write 形式适合在页面加载时输出静态内容；innerHTML 形式适合动态更新某个容器的内容。
  3. 压缩空白会把多行 HTML 合成一行，减少字符串里的 \\n，但要注意 div 与 span 之间的空格可能影响排版。
  4. 选择单引号时，HTML 属性建议用双引号书写，可以减少转义字符的数量，让代码更易读。
  5. 本工具只做字符串包装，不会对 HTML 做任何安全过滤，请勿用于拼接用户输入的内容（存在 XSS 风险）。
