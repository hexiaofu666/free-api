关于IP地址查询工具介绍：

  1. 用途：查询 IP 地址的归属地（国家/省市）、运营商（ISP）、经纬度等信息，可用于日志分析、风控、访问来源统计等。
  2. 支持内容：
    • IPv4 与 IPv6 地址查询；
    • 留空输入框点"查询本机IP"可直接获取你的公网出口 IP 及归属地；
    • 支持批量查询，一行一个，逐条显示结果。
  3. 数据来源：通过公共免费 IP 归属地接口（ipapi.co / ip-api 等）在线查询，需要联网；单次查询之间有短暂间隔以免触发限流。
  4. 说明：IP 归属地精确到城市级，运营商数据仅供参考；查询结果由第三方接口提供，本工具不存储任何查询记录。
