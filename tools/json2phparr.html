PHP 数组代码

关于JSON转PHP数组介绍：

  1. PHP 数组有两种写法：短数组 []（PHP 5.4+，推荐）与 array()（兼容更老版本），本工具都支持。
  2. JSON 对象会转成关联数组（'key' => value），JSON 数组转成索引数组（直接列出值）。
  3. 字符串中的单引号、反斜杠与 $ 符号会被正确转义，避免 PHP 解析出错。
  4. 如果项目要求全 ASCII 输出，可开启「转义为 Unicode」（\u{} 语法），此时文件里不会出现汉字。
  5. 生成的代码可直接粘贴到 PHP 文件中作为配置数组使用，也可配合 json_encode 反向输出 JSON。
