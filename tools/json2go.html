关于JSON转Go结构体介绍：

    
    
      
  1. 把接口返回的 JSON 转成 Go 的 struct 定义，可直接用于 json.Unmarshal，省去手写字段与 tag 的重复劳动。
    2. 
      
  2. 字段名自动转为大驼峰（PascalCase），并保留原始键名作为 json:"key" 标签，保证反序列化正确。
    3. 
      
  3. 类型映射：字符串 → string、布尔 → bool、整数 → int、小数 → float64、null → interface{}、对象 → 嵌套 struct、数组 → 切片。
    4. 
      
  4. 数组中的所有元素会合并字段，某字段不是每个元素都出现时，可自动加 omitempty 标记。
    5. 
      
  5. 标签列已按 gofmt 风格对齐，可直接粘贴进编辑器格式化。
    6.
