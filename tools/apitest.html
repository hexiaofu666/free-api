关于在线API测试工具介绍：

  1. 浏览器发起跨域请求受同源策略限制：目标接口必须返回 Access-Control-Allow-Origin 才能成功，这与 Postman 等桌面工具不同。
  2. 请求头按「名称: 值」每行一条填写，例如 Content-Type: application/json 与 Authorization: Bearer xxx。
  3. 响应体会自动尝试 JSON 格式化，方便阅读结构化数据；非 JSON 内容原样显示。
  4. 响应区会显示状态码、耗时与响应大小，可用于粗略评估接口性能与返回体量。
  5. 测试自己站点的接口最方便（同源无跨域限制），例如 tools.hdemba.cn 的开放 API。
