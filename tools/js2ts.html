关于JS转TypeScript介绍：

  1. 支持为 const/let/var 声明添加类型注解，字符串→string、整数与小数→number、true/false→boolean、数组→any[]。
  2. 函数参数默认标注为 any（可手动细化）；返回值会读取函数体里的 return 语句进行推断。
  3. 工具会为对象字面量生成同名 interface（首字母大写），并自动加上 as 断言，减少手动整理结构的工作量。
  4. 转换结果是起点而非终点：复杂的泛型、联合类型与第三方库类型仍需人工完善。
  5. 建议转换后开启 TypeScript 的 strict 模式，逐步把 any 替换为精确类型。
