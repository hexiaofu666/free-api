关于MIME类型介绍：

  1. MIME 类型（又称媒体类型 / Content-Type）用于告诉浏览器和服务器数据的格式，格式为「主类型/子类型」，如 text/html。
  2. 在 Nginx 中通过 mime.types 文件配置；服务器返回错误的 MIME 类型会导致 CSS 不生效、图片无法显示、字体被拒绝加载等问题。
  3. 常见坑：woff2 字体需返回 font/woff2；JSON 应为 application/json；SVG 建议 image/svg+xml。
  4. 本表按「文本 / 图片 / 音视频 / 字体 / 应用」分类整理，支持按扩展名或类型关键词实时搜索。
  5. 点击上方分类按钮可快速筛选，输入关键词则在同一列表中模糊匹配。
