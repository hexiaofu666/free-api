关于 HMAC 介绍：

  1. HMAC（Hash-based Message Authentication Code）是带密钥的哈希消息认证码，同时验证消息完整性与来源身份。
  2. 计算公式：HMAC(K, M) = H((K⊕opad) ∥ H((K⊕ipad) ∥ M))，其中 opad/ipad 为固定填充常量。
  3. 只有持有相同密钥的一方才能计算出相同的 HMAC，广泛用于 API 签名（如各大云服务）、Webhook 校验、JWT 签名等。
  4. 支持 MD5 / SHA-1 / SHA-256 / SHA-384 / SHA-512 五种底层哈希；新系统建议优先使用 SHA-256 及以上。
  5. 消息与密钥均按 UTF-8 编码；结果输出 128 位十六进制摘要（MD5 为 32 位）。
